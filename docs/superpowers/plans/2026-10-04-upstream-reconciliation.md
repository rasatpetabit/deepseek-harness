## Review Focus

- Clean root auto-login must not accept query-bearing requests, non-GET requests, other paths, or forged forwarding headers; Task 2 owns negative tests.
- Public HTTPS clients must not downgrade Origin to HTTP or omit WebSocket Origin; Task 3 owns runtime proxy rejection tests.
- A build changing HEAD, dirtying tracked source, or creating untracked source must fail before promotion; Task 4 owns controlled moving-source tests.
- Historical children absent from the inventory must not be silently ignored by migration; Task 5 owns complete inventory and catalog failure checks.
- A plugin merely registering a route does not establish model/effort selection or Hindsight recall/tool capability; Task 5 owns consumed-capability assertions without inference.
